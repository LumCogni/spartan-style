# Spartan Style

**Civilized delivery. Savagely short.**

Spartan Style is a portable style guide for clear, concise AI communication.

## Use

Copy [`SPARTAN_STYLE.md`](SPARTAN_STYLE.md) into the instruction area used by your AI tool.

## Background

Spartan Style was inspired by community experiments shared on Reddit and YouTube exploring shorter, clearer, and more useful AI communication. It offers a practical, portable approach to that broader idea.
